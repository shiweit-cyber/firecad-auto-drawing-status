# FireCAD Public Status Mirror

This directory is a prepared public status channel for the FireCAD auto drawing project.

It is intended for GPT to read automated test status without requiring Tang boss to manually copy reports.

## Scope

- Contains status summaries and selected automation reports only.
- Does not contain source code.
- Does not contain customer drawings.
- Does not contain credentials, keys, or tokens.
- Does not contain real project materials.
- Does not contain DWG, DXF, PDF, images, archives, or executable assets.

## Planned Public Repository

- Suggested repository name: firecad-auto-drawing-status
- Main source repository remains private: firecad-auto-drawing
- This mirror is prepared locally first and must not be pushed to a public repository until Tang boss confirms.
